# Woorisseum module rules baseline
#
# 기준: AGENTS.md의 모듈 의존 방향과 domain 독립성.
# 검사: ./gradlew moduleRules
# 검토한 예외 반영: ./gradlew moduleRulesBaseline
# 규칙 구현: build-logic/src/main/kotlin/com/woorisseum/buildlogic/ModuleRules.kt
#
# 허용하는 직접 프로젝트 의존 관계 (검사 기준 설명):
# :androidApp -> :shared
# :shared -> :core:domain, :core:data, :core:designsystem, :feature:*
# :feature:* -> :core:domain, :core:designsystem
# :core:data -> :core:domain
# :core:domain -> 없음
# :core:designsystem -> 없음
#
# domain 운영 의존: Kotlin 기본 구성, Coroutines, Datetime.
# domain에는 UI, DI, 저장소 SDK 의존을 허용하지 않음.
# iosApp은 Xcode 프로젝트이므로 Gradle 모듈 검사 대상에서 제외.
#
# 아래에는 승인한 기존 위반만 한 줄씩 정렬하여 기록함.
# 형식: dependency: <source-module> -> <target-module>
# 형식: domain-library: :core:domain -> <group>:<artifact>
# 형식: domain-test-library: :core:domain -> <group>:<artifact>
# 형식: domain-plugin: :core:domain -> <plugin-id>
# '#'으로 시작하는 설명과 빈 줄은 Baseline 비교 대상에서 제외함.
